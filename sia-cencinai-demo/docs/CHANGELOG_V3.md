# Changelog — Prototipo v3

## 16/09/2026

### Removido
- Control de calidad Regional como módulo/pestaña.
- Workflow validar/devolver/corregir.
- Intensidad/frecuencia/persistencia obligatorias en valoración.
- Selectores masivos de personas.

### Agregado
- Rol Establecimiento.
- Navegación por rol.
- Búsqueda por identificación/nombre.
- Filtros jerárquicos.
- Especificación adicional para cualquier factor seleccionado.
- Impresión de referencia.
- Carga simulada desde Excel estandarizado.
- Programación de sesiones y atenciones.
- Alertas por programación vencida.
- Flujo de traslado origen/destino.
- Reportes independientes del cierre.
- Reporterías con año/período y ámbito.
- Personas únicas atendidas vs total de atenciones.
- Consolidado dinámico.
- Exportación compatible con Excel.

### Renombrado
- Intervenciones → Atenciones.
- Instrumentos → Documentos.

### Experimental
- OCR.
- Offline/sincronización avanzada.
