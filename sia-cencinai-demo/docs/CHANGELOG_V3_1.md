# Changelog — Prototipo v3.1

## 01/10/2026

### Terminología
- Se renombró la sección **Personas** como **Clientes/beneficiarias** en la navegación y principales textos de interfaz.
- Se aclaró que esta consulta incluye todos los clientes/beneficiarias del ámbito autorizado, tengan o no un caso de Atención Interdisciplinaria.

### Filtros
- Se incorporaron filtros jerárquicos de Región, Oficina Local y Establecimiento en Clientes/beneficiarias, además de estado de servicio.
- Los selectores de establecimiento muestran explícitamente el prefijo **Establecimiento** incluso después de seleccionar una opción.

### Simulación por rol
- El encabezado de demostración ahora identifica ámbito, nivel y rol activo de forma explícita.

### Datos de demostración
- Se amplió el volumen de datos sintéticos en clientes/beneficiarias, referencias, casos, sesiones, atenciones grupales, documentos, coordinaciones, reportes y programación.
- La Oficina Local Alajuela cuenta con aproximadamente 6–9 ejemplos en los módulos principales para facilitar pruebas y demostraciones.

### Compatibilidad de la demo
- Se actualizó la clave de almacenamiento local a v3.1 para que los nuevos datos sintéticos se carguen sin quedar ocultos por una sesión previa del prototipo v3.
